📋 Overview

This project performs a comprehensive risk-return analysis on equity securities using real market data. The goal is to quantify the relationship between risk and expected return — measuring volatility, correlation structure, and performance attribution across individual stocks and portfolios.

Built on core financial theory including CAPM and Modern Portfolio Theory, the analysis translates empirical market data into actionable portfolio insights and performance diagnostics.

⚙ Methodology
01
Data Collection & Cleaning
Pull historical equity price data, compute daily log returns, and handle missing data and corporate actions.
02
Volatility Estimation
Calculate historical and rolling volatility using standard deviation of returns. Analyze how risk evolves across market regimes.
03
Regression Analysis
Run CAPM regression to estimate beta — the systematic risk relative to a market benchmark — and isolate alpha (excess return).
04
Portfolio Performance Metrics
Compute Sharpe ratio, Sortino ratio, max drawdown, and information ratio across portfolios for a full performance picture.
05
Correlation & Diversification
Build correlation matrices and analyze how diversification reduces portfolio variance across asset combinations.
